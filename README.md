# STARFABLE — 星海の果て

スマートフォンの**横向き全画面**で遊ぶ、ブラウザ製の 3D 宇宙アドベンチャーです。
ビルドは不要です。`index.html` と `src/`、`assets/`、`vendor/` を HTTP で配信します。Three.js を同梱しており、モデル・効果音・BGM は実行時に生成します。

宇宙船・施設・地表の既存30素材を画像ベースに更新し、耐熱セラミック、カーボン繊維、酸化した合金、医療用ビニール、砂岩、氷、濡れた舗装など40素材を追加しました。素材ごとの色・法線・粗さと、植物・惑星・雲・星雲・太陽・リングの画像は WebP です。ファイルは `assets/textures/packs/` の ZIP を展開すると確認でき、ゲームは必要な ZIP を読み込みます。端末の数値、標識の文字、天候や発光のアニメーションは実行時に描画します。

### AI 生成テクスチャ（gpt-image-2.5-sunburst）

Claude Code のスキル `.claude/skills/gpt-image-textures/` で、`gpt-image-2.5-sunburst` に 1:1・2880×2880（1:1 で使える最大サイズ）・quality=medium の画像を描かせます。画像は 3×3 のマス目になっていて、1 枚から 9 枚のテクスチャを切り出します。切り出した画像は継ぎ目なしに加工し、法線・粗さの画像も作ります。明るさは置き換える前の画像の平均に揃えます。

結果は `assets/textures/packs/ai-*.zip` に入り、既存のパックより後に登録されるので、同じ名前の画像を置き換えます（一覧は `src/gfx/texture-packs-ai.js`）。

**救助船の出動**: アトラスの「救難指令室」で司令か端末に話しかけ、出動機数（3 / 5 / 10 / 15 機）を選びます。発令後にアトラスを出ると、係留クレードルから順に発進して地球へ向かう姿が見えます。地球に降りると、街の広場に描かれた「緊急着陸帯」（最大 15 か所・緑の光柱が目印）に機体と救難ボット、救護テントが展開しており、後部ランプから機内に入れます。地球に災害警報が出ているときは、必要な機数を 1 日以上活動させてから帰還させると特別報奨が出ます。

**外装の艤装と交通**: 追加の 4 ステーションは、形の上にさらに艤装を重ねています。アトラスは発着番号の描かれた係留クレードル、甲板の給油車と救援物資、脱出ポッドの列、太陽電池翼、接舷中の救急艇、回転レーダーと探照灯。メガトンは窓の格子、船名板の電飾、採光ミラーの筋交い、港のコンテナ帯と接岸中の貨物船、外周トラム、貨物船の航路、スポークの昇降機、炉のプロミネンス。ファイザーは鎖の継手と水素結合の灯（A-T は 2 つ、G-C は 3 つ）、タンクの配管と銘板、六角形の進入ゲート、流れる培養液、巡回する試料カプセル。ウェポンは給電ケーブル、消炎器、垂直発射筒、碍子と母線、弾速計測ゲート、射線のブイ、古い標的の残骸があり、試射に合わせて放熱フィンが赤熱し、蓄電器が放電し、砲口から衝撃の環が広がります。各ステーションには進入ゲートと航路ブイ、数百の航行灯が付きます。

### メガトンの街（第 7 居住甲板）

メガトンの船内は、ほかのステーションのような「数部屋の基地」ではなく、1 つの甲板に詰まった街です（`src/world/megaton.js`）。

- **9 つの街区**: 錨町（いちばん古い路地。狭く低く折れ曲がり、辻に祠と銭湯）／展望町（外壁の窓に面した住宅と展望ラウンジ）／市場（市場ホールとフードコート）／緑ヶ丘団地（中廊下の家族向け住戸、光庭、公園）／学校通りと中央区（区役所・図書館・保育園・郵便局・交番・診療所・学校・駅）／鋳物町（工員寮・社員食堂・鋳造工場・機械室、炉心見学デッキ）／第 9 区（中庭を囲む環状通路）／港町（倉庫と長屋）／船員街（港の北の下宿街と船員会館）／ひかり台（南の新しい団地）
- **通路は手で引いた折れ線**: 区間ごとに幅（1.8〜11m）・天井の高さ・中心線のずれが違い、継ぎ目には骨組みの枠が立ちます。行き止まり・袋小路・ぐるりと回れる路地・小さな溜まりもあります。街区の境には気密扉があります
- **住戸は 1 戸ずつ違う**: 床（明るい木・濃い木・寄木・白いタイル）、壁紙（花柄・縦縞・若草色・砂壁）、天井（木目・竿縁）、7 色の玄関扉、カーテン・ベッドカバー・ソファ・冷蔵庫・台所の色違い、本棚・テレビ・時計・カレンダー・家族写真、和室のふすま・障子・たんす・のれん、子ども部屋のおもちゃ棚と絵を、家ごとに選びます。通路沿いに、間口も奥行きも揃わない区画を詰めて作ります。間取り（1 室／台所 + 和室／LDK + 寝室 + 子ども部屋 + 浴室）、玄関扉の色と開く向き、扉の位置（隣と玄関を寄せ合う並びが多い）、家具の置き方、玄関先の私物（鉢植え・傘・段ボール・靴）、台所の小窓、表札と玄関灯をすべて戸ごとに変えています。住戸の玄関の内側には土間（石の床と上がり框、脱いだ靴）があります。空き部屋、コインランドリー、ゴミ置き場、自転車置き場、集会所、ポンプ室、上の階へ続く（工事中の）階段室も混ざります。外壁に面した部屋だけは本物の窓から宇宙が見えます
- **通路の変化**: ベンチや自販機のある浅い溜まり（41 か所）、壁から張り出した配管シャフト、ダクトを包んだ下がり天井、閉まった店のシャッターが、通路の幅と天井の線を所々で崩します。別の通りへの継ぎ目の上には行き先の札があります
- **上の階の家並み**: 天井の高い本通り・中央広場・公園の壁の上部には、上の階の住戸の窓（灯りとカーテン）、ベランダ（洗濯物・鉢植え）、室外機、縦の配管が並び、街が上へ積み重なって見えます
- **明るさ**: 天井の低い路地も含めて全体を明るくし、公園と広場には発光する人工の空を張っています
- **軽さ**: 758 部屋あるので、開口（扉・継ぎ目）を通して実際に見通せる部屋だけを描き（2D のポータル判定）、遠い部屋は家具を省いて殻だけを描きます。家具の形は、その部屋を近くで初めて見たときに作ります（当たり判定と調べられる物は最初から登録済み）。人物の形は色ごとに共有しています。照明は、見えていない部屋の灯りを使わず、隣の部屋の灯りは戸口から漏れる分だけに弱めます（小さな部屋が壁越しの灯りで白く飛ばないように）

**内装の主役**: アトラスのホールの慰霊碑と格納庫の操縦シミュレーター、メガトンの展望ラウンジの太陽系儀と中央駅の発車標、ファイザーの培養槽・遠心分離機・電子顕微鏡、ウェポンの訓練標的と試射監視卓（次の試射までの秒読みが動きます）。

- **局所破壊**: 被弾・衝突した場所の外板だけが欠け、周囲が凹んで焦げます。破片も飛びます。傷は修理するまで残ります。
- **建物との当たり判定**: 都市のビルには飛行中も徒歩でもぶつかります。平らな屋上や桟橋には着陸できます。
- 交易・任務・賞金首・機体強化・セーブ（ブラウザの localStorage）。

## 画質と軽さの設定

タイトル画面と「MENU → 設定」から変更できます。**解像度は自動では変わりません。**

- **解像度**: 540p（既定）/ 720p / 1080p / 最大。下げてもモデルやテクスチャの細かさは変わりません。
- **描画距離**: 近い / 標準 / 遠い。遠くの建物・木々を描く範囲です。
- **画質**: ロー / ミドル / ハイ / ウルトラ（影・反射・アンチエイリアスの品質）。ハイとウルトラでは FXAA を使います。ローではブルームを低い解像度で計算します。浮動小数点の描画ターゲットを作れない端末では、8 ビット描画に切り替わり、ブルームと環境マップによる反射を省きます。
- **視点の感度**（MENU）: 歩いているときに見回す速さ（低 / 標準 / 高）。
- **FPS 表示**（MENU）: 画面上部に 1 秒あたりの描画回数を出します。設定を選ぶときの目安にどうぞ。

軽くするための仕組み: 視界の外にあるタイル（街区・森）は描かない、室内は今いる部屋と隣の部屋だけ描く（端末の画面も見えている部屋のぶんだけ更新）、木・下草・作物・岩・住宅はカメラの周囲だけ生成する、路面の反射は路面が見える場所でだけ描く、メニューを開いている間は 3D を描き直さない、遠くのステーションの動く部品は間引いて動かす、サウンド OFF の間は音声処理を止める。アプリを切り替えると自動で一時停止します。

## 公開方法（GitHub Pages）

1. このブランチを既定ブランチにマージする
2. リポジトリの **Settings → Pages → Build and deployment** で *Deploy from a branch* を選び、ブランチと `/ (root)` を指定
3. 表示された URL をスマートフォンで開き、横向きにして「はじめる」をタップ（全画面になります）

手元で試す場合:

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

`file://` で直接開くと ES モジュールが読み込めないため、必ず HTTP で配信してください。

## 正直な注意書き

- 動作確認は**ヘッドレスの Chromium（ソフトウェア描画）でのみ**行っています。実機のスマートフォンでのフレームレートや発熱は未確認です。重い場合は解像度 540p・画質ロー・描画距離「近い」を試してください。
- メガトンの街は、何度作っても同じ配置になります（家具の向きを決める並べ替えに乱数の比較を使うと、ブラウザの最適化の具合で結果が変わるため、決まった手順で混ぜています）。
- メガトンの街は、ヘッドレスの Chromium で各街区・住戸・店の中を撮影して確かめ、781 か所すべての扉・継ぎ目を通り抜けられることを確認しています（家具や小物がふさいでいないか）。
- 追加の 4 ステーションは、外観を途中段階で描画確認したのみで、**内装・救助船の出動・地表への配置・その後に足した外装の艤装と交通・内装の大物は実行確認をしていません**（構文チェックと静的な未定義参照チェックのみ）。そのため、艤装や小道具の 1 つに不具合があっても本体の建造や画面の更新が止まらないよう、失敗した部品だけを飛ばす保護を入れてあります（その場合はブラウザのコンソールに警告が出ます）。向きや位置のずれが残っている可能性があります。アトラスの大格納庫は描画負荷が高めです。
- WebGL2 が必要です。iOS の Safari は全画面 API と画面の向きの固定に制限があるため、縦持ちのときは画面を 90° 回して横向きに表示します。
- 「現実と見分けがつかない」水準の写実表現は、モバイルのブラウザでは実現できていません。物理ベースのマテリアル、HDR ブルーム、反射、室内が見える窓などで可能な範囲まで作り込んだものです。
- 木は板ポリゴン、歩行者と車は簡易モデルです。歩行者・車・列車に当たり判定はありません。
