# STARFABLE — 星海の果て

スマートフォンの**横向き全画面**で遊ぶ、ブラウザ製の 3D 宇宙アドベンチャーです。
ビルドは不要で、`index.html` を HTTP で配信するだけで動きます（Three.js は `vendor/` に同梱。画像・音声ファイルは使わず、テクスチャ・モデル・効果音・BGM はすべて起動時にコードで生成します）。

## 遊べるもの

| | 内容 |
|---|---|
| 宇宙ステーション ×9 | ヘイヴン / ヴァルカン / オーロラ / バスティオン / ローグ / **アトラス / メガトン / ファイザー / ウェポン**。外観も内装も別物で、ドッキングして歩き回れます（造船所・市場・任務掲示板・バー・カジノ・研究所など） |

| 地球（着陸可能） | 曲がった街路と川・橋・モノレールのある巨大都市、港、農園地帯（麦・とうもろこし畑、牧草地の牛）、郊外の住宅地、雪国の村と岩峰、ジャングルの奇岩と古代遺跡、岩礁・洋上プラットフォーム・洋上風車のある海 |

### 追加の 4 ステーション

| | 場所 | 規模 | 見どころ |
|---|---|---|---|
| アトラス救難基地 | 地球軌道 | 大 | 黄金の天球儀を担ぐ発進甲板に救助船 15 機を係留。内部は天球儀のホール、救難指令室、救助船が並ぶ大格納庫、救命救急センター |
| メガトン | ゼファー軌道 | 巨大（全長 3.3km） | 窓の奥に街明かりが見える回転居住筒、逆回転する 2 つのリング、1km 級の採光ミラー、核融合炉と赤熱する放熱板。内部はガラス屋根の大吹き抜けと商店街・連絡列車、メガトン炉心、取引所、空中庭園、駅、鋳造区画、展望ラウンジ |
| ファイザー | サハル軌道 | 中 | 回転する二重らせんの創薬研究ステーション。除染ゲート、二重らせんの吹き抜け、創薬ラボ、製剤ライン、培養ドーム、冷凍保管庫 |
| ウェポン | イグニス軌道 | 小 | ステーションそのものが一門の電磁投射砲で、定期的に標的の小惑星へ試射します（射線に入ると巻き込まれます）。内部は主砲機関部（制御卓から試射できる）、兵装庫、射撃試験場、戦闘指揮所 |

**救助船の出動**: アトラスの「救難指令室」で司令か端末に話しかけ、出動機数（3 / 5 / 10 / 15 機）を選びます。発令後にアトラスを出ると、係留クレードルから順に発進して地球へ向かう姿が見えます。地球に降りると、街の広場に描かれた「緊急着陸帯」（最大 15 か所・緑の光柱が目印）に機体と救難ボット、救護テントが展開しており、後部ランプから機内に入れます。地球に災害警報が出ているときは、必要な機数を 1 日以上活動させてから帰還させると特別報奨が出ます。

**外装の艤装と交通**: 追加の 4 ステーションは、形の上にさらに艤装を重ねています。アトラスは発着番号の描かれた係留クレードル、甲板の給油車と救援物資、脱出ポッドの列、太陽電池翼、接舷中の救急艇、回転レーダーと探照灯。メガトンは窓の格子、船名板の電飾、採光ミラーの筋交い、港のコンテナ帯と接岸中の貨物船、外周トラム、貨物船の航路、スポークの昇降機、炉のプロミネンス。ファイザーは鎖の継手と水素結合の灯（A-T は 2 つ、G-C は 3 つ）、タンクの配管と銘板、六角形の進入ゲート、流れる培養液、巡回する試料カプセル。ウェポンは給電ケーブル、消炎器、垂直発射筒、碍子と母線、弾速計測ゲート、射線のブイ、古い標的の残骸があり、試射に合わせて放熱フィンが赤熱し、蓄電器が放電し、砲口から衝撃の環が広がります。各ステーションには進入ゲートと航路ブイ、数百の航行灯が付きます。

**内装の主役**: アトラスのホールの慰霊碑と格納庫の操縦シミュレーター、メガトンの展望ラウンジの太陽系儀と中央駅の発車標、ファイザーの培養槽・遠心分離機・電子顕微鏡、ウェポンの訓練標的と試射監視卓（次の試射までの秒読みが動きます）。

- **局所破壊**: 被弾・衝突した場所の外板だけが欠け、周囲が凹んで焦げます。破片も飛びます。傷は修理するまで残ります。
- **建物との当たり判定**: 都市のビルには飛行中も徒歩でもぶつかります。平らな屋上や桟橋には着陸できます。
- 交易・任務・賞金首・機体強化・セーブ（ブラウザの localStorage）。

## 操作

**タッチ**（画面左 = 操縦スティック / 画面右 = ボタン、右端 = スロットル）
状況に応じたボタン（ドッキング、オートランド、乗る、入る など）が画面中央下に出ます。

**キーボード**（PC での確認用）

| 場面 | キー |
|---|---|
| 共通 | `W A S D` / 矢印 = 操縦・移動、`Shift` = ブースト / 走る、`E` / `Enter` = 調べる・決定 |
| 宇宙 | `Space` 発射、`F` ミサイル、`T` 照準切替、`Q` `E` ロール、`J` 超巡航、`G` 自動航行、`V` 視点、`Z` `X` スロットル全開 / 停止 |
| 地表（飛行） | `R` / `Space` 上昇、`F` / `C` 下降、`V` 視点 |
| 船内・徒歩 | マウス / 画面右半分ドラッグで視点、`Space` 射撃（敵艦内） |

## 画質と軽さの設定

タイトル画面と「MENU → 設定」から変更できます。**解像度は自動では変わりません。**

- **解像度**: 540p（既定）/ 720p / 1080p / 最大。下げてもモデルやテクスチャの細かさは変わりません。
- **描画距離**: 近い / 標準 / 遠い。遠くの建物・木々を描く範囲です。
- **画質**: ロー / ミドル / ハイ / ウルトラ（影・反射・アンチエイリアスの品質）。

軽くするための仕組み: 視界の外にあるタイル（街区・森）は描かない、室内は今いる部屋と隣の部屋だけ描く、木・下草・作物・岩・住宅はカメラの周囲だけ生成する、路面の反射は路面が見える場所でだけ描く。

## 公開方法（GitHub Pages）

1. このブランチを既定ブランチにマージする
2. リポジトリの **Settings → Pages → Build and deployment** で *Deploy from a branch* を選び、ブランチと `/ (root)` を指定
3. 表示された URL をスマートフォンで開き、横向きにして「はじめる」をタップ（全画面になります）

手元で試す場合:

```sh
python3 -m http.server 8000   # → http://localhost:8000/
```

`file://` で直接開くと ES モジュールが読み込めないため、必ず HTTP で配信してください。

## 構成

```
index.html / style.css   入口と HUD のスタイル
src/main.js              起動・モード切替・メインループ
src/core/                共通関数・音声合成
src/gfx/                 レンダラ（ブルーム・トーンマップ・光条・平面反射）、惑星、エフェクト、手続きテクスチャ（textures2.js = 追加分）、局所破壊
src/world/               定義データ、機体・ステーション・内装・地表（earth.js = 地球）
                         追加 4 基: stations2.js（外観）/ blueprints2.js（間取り）/ props2.js・props3.js（大道具）/ rescue.js（救助船とボット）
src/game/                宇宙 / 船内 / 地表の各モードとセーブデータ
src/ui/                  入力・HUD・各種パネル
vendor/three/            Three.js r170
```

デバッグ用 URL: `?auto=space|interior|surface&body=terra&q=medium&res=540&dist=mid` でタイトルを飛ばして各モードを直接開けます（例: `?auto=space&near=megaton` / `?auto=interior&type=station&id=atlas&at=23,80,3.14` / `?auto=interior&type=rescue`）。

## 正直な注意書き

- 動作確認は**ヘッドレスの Chromium（ソフトウェア描画）でのみ**行っています。実機のスマートフォンでのフレームレートや発熱は未確認です。重い場合は解像度 540p・画質ロー・描画距離「近い」を試してください。
- 追加の 4 ステーションは、外観を途中段階で描画確認したのみで、**内装・救助船の出動・地表への配置・その後に足した外装の艤装と交通・内装の大物は実行確認をしていません**（構文チェックと静的な未定義参照チェックのみ）。そのため、艤装や小道具の 1 つに不具合があっても本体の建造や画面の更新が止まらないよう、失敗した部品だけを飛ばす保護を入れてあります（その場合はブラウザのコンソールに警告が出ます）。向きや位置のずれが残っている可能性があります。メガトンの大吹き抜けとアトラスの大格納庫は描画負荷が高めです。
- WebGL2 が必要です。iOS の Safari は全画面 API と画面の向きの固定に制限があるため、縦持ちのときは画面を 90° 回して横向きに表示します。
- 「現実と見分けがつかない」水準の写実表現は、モバイルのブラウザでは実現できていません。物理ベースのマテリアル、HDR ブルーム、反射、室内が見える窓などで可能な範囲まで作り込んだものです。
- 木は板ポリゴン、歩行者と車は簡易モデルです。歩行者・車・列車に当たり判定はありません。
